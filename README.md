# Hi, I'm Isak

A systems-minded developer, naturally curious and stubborn to a fault.

I care about **open source**, **fast code**, and **clean abstractions**.

I feed my restless brain by:

- Building things from scratch
- Hosting my own services
- Making little tools that help me in my everyday life
- Digging into low-level details
- Starting yet another project

At work I usually beef with Java and TypeScript, and at home I nerd out with Rust and Kotlin. On Arch Linux, of course.
